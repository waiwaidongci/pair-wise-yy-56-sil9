# 钢结构焊缝台账、无损检测和返修闭环平台

源提示词编号：13。覆盖构件与图纸焊缝台账、二维定位、焊工资质和检测比例预警、批量检测计划、缺陷记录、返修/复检状态、Apollo GraphQL 数据层、版本快照、签字锁定和完整追溯。

## 焊工资质范围账（新增）

把 **焊工资质（证书）× 焊接工艺卡（WPS）× 焊缝 × 检测计划** 接成一本“范围账”，纠正现场排检只看焊工姓名的问题。

规则实现在与框架解耦的纯函数引擎 `src/app/scope/scope.engine.ts`：

1. 每道焊缝按**作业日**取当时已生效工艺卡的方法、材料组别、位置（同卡号多版本取作业日当天最新版）。
2. 证书必须**同时覆盖方法、材料组别、位置三项**且作业日在有效期内，焊缝才“可排入”；缺项逐项标出，三项覆盖但已过期单列。
3. 两份及以上证书都覆盖时，按**最早到期**安排，并列出全部“重叠覆盖”的证书。
4. 工艺卡发布新版后，受影响的**待执行**计划自动“退回重算”；**已签字/已执行**批次保留落账时的依据快照（`BasisSnapshot`）不变。
5. 两个录入端提交**同一证书号**：先到“生效”、后到挂“冲突”。
6. 保存失败挂“待重试”，按证书号“重试续办”复用原记录，幂等、**不重复排计划**。
7. 旧焊缝无工艺卡号 → “待补录工艺卡”，不参与排检。

页面入口：顶部导航「范围账」（路由 `/scope`），含范围核对、检测计划与签字、工艺卡更新重算、证书录入/冲突四个页签。

```bash
npm run test:scope   # 纯引擎规则单测（tsc 编译到 dist-scope 后用 node --test 运行）
```
